# 💼 Personal Portfolio Website

🚀 My personal portfolio website built with Django to showcase my skills, projects, certifications, resume, and professional journey.

## ✨ Features

- 👩‍💻 About Me section
- 🛠️ Skills and technologies
- 📂 Project showcase
- 📜 Certifications
- 📄 Resume download
- 📱 Responsive design

## 🧰 Technologies Used

- 🐍 Python
- 🌐 Django
- 🎨 HTML5 & CSS3
- ⚡ JavaScript
- 🗄️ SQLite
## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/harshitha-c-2004/portfolio.git
```

### 2. Navigate to the project folder

```bash
cd portfolio
```

### 3. Run the Django server

```bash
python manage.py runserver
```
